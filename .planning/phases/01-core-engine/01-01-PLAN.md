  <action>
Create TapTempo.swift with basic 4-tap averaging (not full 8-tap statistical analysis - that's Phase 3).

`class TapTempo`:
- Private array of tap timestamps `[Date]`
- Private constant `maxTaps = 8` (window size)
- Private constant `resetInterval: TimeInterval = 2.0` (gap that resets taps)
- Private constant `minTapsForBPM = 4` (minimum taps before returning BPM)

Public methods:
- `func recordTap() -> BPM?`
  - Record current Date
  - If gap from last tap > resetInterval, clear previous taps
  - Keep only last maxTaps timestamps
  - If taps.count < minTapsForBPM, return nil
  - Calculate intervals between consecutive taps
  - Use simple average of intervals (Phase 3 adds outlier rejection)
  - Convert average interval to BPM
  - Return BPM(value:) - may return nil if calculated BPM outside valid range

- `func reset()`
  - Clear all recorded taps

- `var tapCount: Int` (read-only)
  - Current number of recorded taps

- `var isReady: Bool` (read-only)
  - Returns true if tapCount >= minTapsForBPM

Use @MainActor for thread safety since this will be called from UI.

Algorithm for BPM calculation:
1. intervals = [taps[1] - taps[0], taps[2] - taps[1], ...]
2. averageInterval = intervals.reduce(0, +) / Double(intervals.count)
3. bpm = 60.0 / averageInterval
