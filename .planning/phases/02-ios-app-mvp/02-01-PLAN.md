  <action>
Create AudioSessionManager class that:
1. Configures AVAudioSession with `.playback` category (enables background audio)
2. Activates session on configureForPlayback()
3. Registers for interruption notifications (phone calls, alarms)
4. Posts notification when interruption ends with shouldResume flag
5. Tracks isConfigured state to avoid redundant configuration

Pattern from research:
```swift
import AVFoundation

class AudioSessionManager {
    private var isConfigured = false

    func configureForPlayback() throws {
        guard !isConfigured else { return }
        let session = AVAudioSession.sharedInstance()
        try session.setCategory(.playback, mode: .default)
        try session.setActive(true)
        // Register for interruptions
        NotificationCenter.default.addObserver(...)
        isConfigured = true
    }
}
```

Include custom notification name `.audioInterruptionEnded` for ViewModel to observe.
