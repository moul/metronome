<task type="auto">
  <name>Task 1: Create BeatIndicatorView with pulse animation</name>
  <files>Metronome/Views/BeatIndicatorView.swift</files>
  <action>
Create BeatIndicatorView that displays visual beat feedback:

1. Access viewModel from @Environment(MetronomeViewModel.self)
2. Display beat number (viewModel.currentBeat + 1, since engine uses 0-based)
3. Create pulsing circle animation triggered by beat changes
4. Use different color for accent beats (viewModel.isAccent)
5. Use onChange(of: viewModel.currentBeat) to trigger animation

Animation pattern from research:
```swift
@State private var animationTrigger = false

ZStack {
    Text("\(viewModel.currentBeat + 1)")
        .font(.system(size: 72, weight: .bold))

    Circle()
        .stroke(viewModel.isAccent ? Color.red : Color.blue, lineWidth: 4)
        .scaleEffect(animationTrigger ? 1.5 : 1.0)
        .opacity(animationTrigger ? 0.0 : 1.0)
        .animation(.easeOut(duration: 0.3), value: animationTrigger)
}
.onChange(of: viewModel.currentBeat) { _, _ in
    animationTrigger = true
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) {
        animationTrigger = false
    }
}
```

Key: Visual MUST be driven by engine state (viewModel.currentBeat), NOT a separate timer.
  </action>
  <verify>File exists with onChange(of: viewModel.currentBeat) animation trigger</verify>
  <done>BeatIndicatorView pulses in sync with audio beats, accent is visually distinct</done>
